# How to Started
**required JAVA=21**
```bash
gradle bootRun
# or
./gradlew bootRun
```

---

### Endpoint

| Method | Path | action |
| ----------- | ----------- | ----------- |
| `GET` | /coffees | ดูเมนูทั้งหมด |
| `GET` | /coffees/{id} | ดูเมนู 1 รายการตาม id |
| `POST`|  /coffees | เพิ่มเมนูใหม่ (ส่งข้อมูลมาเป็น JSON) |
| `PUT` | /coffees/{id} | แก้ไขเมนูเดิมตาม id |
| `DELETE` | /coffees/{id} | ลบเมนูตาม id |
